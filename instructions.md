Transcom Group Data Analysis:
You are given a Transcom Group dataset. The dataset contains information about Transcom
Group based restaurant names, ratings, votes, online ordering, restaurant types, and cost for two
people. Using Python, analyze the dataset and answer the following simple questions:

1. Load the chillox dataset using Pandas.
2. Display the first 5 rows of the dataset.
3. Check if there are any missing values.
4. Clean the restaurant rating (rate) column and convert it to numbers.
5. Find the most common type of restaurant.
6. Find which restaurant type has the highest number of votes.
7. Find the restaurant with the highest number of votes.
8. Create a chart to show how many restaurants provide online ordering.
9. Create a chart to show the distribution of restaurant ratings.
10. Find the most common cost for two people.
11. Compare restaurant ratings for online and offline ordering using a chart.
12. Create a heatmap to show the relationship between restaurant type and online ordering.
13. Write 3–5 simple conclusions based on your findings.
